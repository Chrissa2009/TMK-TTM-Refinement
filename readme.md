# TMK-TTM-Refinement

This repository contains refined Task-Method-Knowledge (TMK) models for five representative lessons in the TMK-TTM replication project. Each lesson was revised to make the task, method, and knowledge structure more explicit, consistent, and easier to compare across different problem-solving approaches.

## What this repository captures

These refinements emphasize how TMK models can represent:

- a clear task goal and its expected outcome
- the control flow of the method used to achieve it
- the knowledge elements needed to support the method
- the relationship between examples, hypotheses, states, and learned concepts

Across these lessons, the modeling focus shifts from specific domain content to a reusable structure for describing how intelligent systems solve problems.

## Refined lessons

- 03 Means-End Analysis: models how an agent reduces differences between current and goal states through operators and subgoals.
- 04 Production Systems: represents rule-based decision making through working memory, production rules, and action selection.
- 06 Learning by Recording Cases: captures case-based learning through storing, retrieving, and reusing prior experiences.
- 07 Case-Based Reasoning: formalizes how new problems can be solved by retrieving similar past cases and adapting their solutions.
- 10 Version Spaces: illustrates concept learning through candidate elimination, specific/general boundaries, and convergence over labeled examples.

## Repository structure

- Each lesson folder contains refined TMK artifacts for knowledge, methods, and tasks.
- The final folders hold the most polished version of each lesson’s TMK representation.
- The notes files summarize the key modeling improvements made during refinement.
